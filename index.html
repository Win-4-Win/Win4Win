Win4Win v0.1.1 — Script de instalación y configuración.

Instala los programas del catálogo con winget, configura navegadores y personaliza el entorno de escritorio.

Instrucciones de uso

  1. Descarga Win4Win.zip desde el botón de descargas.
  2. Extrae el ZIP en una carpeta local.
  3. Consulta el README.md incluido para ver las instrucciones y opciones de ejecución.
  4. Para iniciar la instalación, ejecuta exec-main-v0.1.1.bat y acepta la solicitud de permisos de administrador.

Programas incluidos

  • Navegadores: Firefox, Chrome, Brave
  • Multimedia: VLC, K-Lite Codec Pack, aTube Catcher
  • Utilidades: WinRAR, Adobe Acrobat Reader, PDFgear
  • Seguridad: AutoFirma

Requisitos

  • Windows 11
  • winget instalado (incluido por defecto en Windows 11)
  • Privilegios de administrador
  • Conexión a internet

[ Preguntas frecuentes ]

El script automatiza la instalación de programas mediante winget, configura los navegadores web (página de inicio, extensiones) y personaliza el entorno de escritorio (barra de tareas, menú Inicio, iconos). Todo se ejecuta de forma silenciosa y registra un log de la instalación.

El código es abierto y puedes revisarlo antes de ejecutarlo. Descarga software únicamente desde fuentes oficiales (Microsoft Store, web de los editores) mediante winget. No contiene activadores, cracks ni software no licenciado. Recomendamos leer el script y verificar los hashes de los descargables.

En la versión actual (v0.1.1), el script instala un catálogo fijo de programas. Puedes editar la lista $programas al inicio del .ps1 para personalizarlo. En futuras versiones, la web permitirá elegir los programas directamente sin editar el script.

Sí. El script requiere privilegios de administrador para instalar programas y modificar la configuración del sistema. Si no tienes permisos, el script intentará auto-elevarte; si no puedes, no se ejecutará.

El script está diseñado y probado para Windows 11. Aunque winget existe en Windows 10, algunas configuraciones de personalización pueden no funcionar correctamente. No garantizamos el funcionamiento en versiones anteriores.

winget detecta automáticamente los programas ya instalados y los salta. El script es idempotente: puedes ejecutarlo varias veces sin efectos secundarios. Solo se instalarán los programas que falten.

Todo el código está disponible en nuestro repositorio de GitHub: Win-4-Win en GitHub. Puedes revisar los scripts, reportar problemas y contribuir al proyecto.

winget es el gestor de paquetes oficial de Microsoft para Windows. Permite instalar, actualizar y eliminar programas desde la línea de comandos de forma automatizada. Viene incluido en Windows 11 y se descarga desde la Microsoft Store.
